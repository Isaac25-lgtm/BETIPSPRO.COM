# Response to the 2026-10-20 code reviews

Fixes for the findings in `2026-10-20-code-and-model-review.md` (R-01 to R-25) and
`2026-10-20-follow-up-code-review.md` (F-01 to F-10). Each fixed finding has a regression test that reproduces the
reported failure (`tests/integration/hardening.test.ts`, `model-pipeline/tests/test_models.py`).

`npx tsc -b --force` clean, `npm run build` passes, `npm audit --omit=dev`: 0 vulnerabilities.

## Deferred (and why)

- **Staged run activation (R-12)** and **frozen evidence snapshots (R-11):** need an active-run pointer and evidence
  storage per report version across every read path; worth doing before automated refresh.
- **Automatic refresh (R-14):** the Python fit runs on the owner's machine; automating it needs a scheduled runner with
  credentials. Settlement already runs automatically.
- **Historical availability (R-04):** provider data does not include first-observed times for old results.
